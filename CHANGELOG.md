# Changelog

## 1.1.2 - 2026-08-25

- Initial public standalone release.
- Tracks Ancient Arts empowerment after Darkest Night and whether it occurred
  during a real Shadow Dance.
- Adds independent combat, encounter, keystone, and session statistics.
- Adds an optional standalone one-to-three-target Eviscerate-range rule.
- Adds reload-safe session persistence and a scrollable history browser.
- Adds native Blizzard Settings controls with LibSharedMedia fonts and textures.
- Uses the Ancient Arts/Nightblade artwork as the addon icon.
